## Summary

Joshua introduces Claude's Managed AI Agents feature and walks through a 5-step process to get one running. He positions it as a major time-saver: agents that previously took weeks to build can now be set up quickly because Claude handles authentication, sandboxing, checkpointing, and tool connections out of the box.

## The 5-Step Process

1. **Create a project folder** — using a terminal command (not shown in transcript)
2. **Install the Agent SDK** — via a package manager command
3. **Get an API key** from the Claude console and set it as an environment variable
4. **Ask Claude to write an agent script** — describe what you want the agent to do and which tools to connect
5. **Customize the agent** — add tools and a system prompt

Solid beginner-friendly overview. The video is light on specifics (no actual commands shown in the transcript) but does a good job of demystifying Managed AI Agents for a non-technical audience. The promise of daily follow-up videos on common agent types is a good hook.
